Merge maps
Load as many maps as you like: each one takes as many cells as it has sectors (a 6×6 map is 6 cells wide and 6 tall). Drag it anywhere on the board — from the strip above, or a map that is already placed. Drop it onto another map to overlap them. The board is just working room: the merged map is cut down to the area your maps actually cover, so empty space around them is dropped, and empty cells in between become flat empty ground. Each map's textureset is read from setting.txt: if the file is not inside the map folder, link the YmirWork/textureset folder below, once. Regenerate server_attr after merging.
